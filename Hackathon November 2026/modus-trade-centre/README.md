# Modus Centre — конкурсный MVP

**Назначение:** единая система обратной связи сотрудников и клиентов ГК «Модус Трейд». Проект независим от Modus Voice и игры «Серпантин Go».

## Демо-сценарий для жюри (3–5 минут)
1. Сотрудник авторизуется и отправляет предложение об улучшении процесса.
2. В кабинете руководителя появляется новое обращение.
3. Руководитель берёт его в работу, оставляет ответ и завершает рассмотрение.
4. Сотрудник видит обновлённый статус и историю действий.
5. Руководитель показывает статистику обращений и состояние интеграций.

## Что уже реализовано в коде
- Роли: клиент, сотрудник, руководитель, директор; серверная проверка видимости и прав изменения.
- Обращения с темой, описанием, категорией, приоритетом, историей статусов.
- Обновления интерфейса через Server-Sent Events.
- Демо-набор вымышленных пользователей и заявок.
- Сохранение общего состояния в PostgreSQL при наличии DATABASE_URL; без БД — временная память процесса.
- Подключаемый адаптер корпоративных систем; реальная интеграция зависит от настроек компании.
- PWA-манифест для установки сайта на телефон.

## Как запустить
```bash
npm install
# Установить DEMO_ACCOUNT_PASSWORDS — JSON с паролями пользователей, минимум 12 символов
# Например: {"staff-1":"DemoPass12345!","manager-1":"DemoPass12345!","director-1":"DemoPass12345!"}
npm start
```
Секреты хранить в переменных окружения, **не коммитить**. Для постоянного хранения указать `DATABASE_URL`.

## Критерии приёмки
- [ ] Вход сотрудника с корректным паролем, отказ при неверном.
- [ ] Сотрудник создаёт обращение, видит его в списке.
- [ ] Сотрудник не может изменить статус через прямой PATCH.
- [ ] Руководитель меняет статус, история фиксирует действие.
- [ ] Сотрудник видит обновление без перезагрузки.
- [ ] После перезапуска с PostgreSQL заявки остаются.
- [ ] Внешний клиент не видит чужие обращения.
- [ ] Интерфейс корректно работает на телефоне.
- [ ] Адаптер 1С/Битрикс24 проверяется отдельно с тестовыми ключами.
