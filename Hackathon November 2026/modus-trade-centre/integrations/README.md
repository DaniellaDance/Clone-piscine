# Modus Centre — корпоративные интеграции

Подготовлен отдельный адаптерный слой для **1С**, **Bitrix24** и **PostgreSQL**. Это интерфейсы интеграции, **не действующее подключение** к закрытым базам компании.

## Переменные окружения Render (только секреты, не GitHub)

- `CORPORATE_INTEGRATION=none|1c|bitrix24|postgresql` (по умолчанию none)
- `CORPORATE_API_URL=https://...` — адрес корпоративного шлюза для 1С / Bitrix24
- `CORPORATE_API_TOKEN` — токен шлюза 1С
- `BITRIX24_TOKEN` — токен Bitrix24
- `CORPORATE_DATABASE_URL` — PostgreSQL connection string (только сервер)
- `INTEGRATION_ADMIN_TOKEN` — отдельный секрет для диагностического API

Никакие данные из корпоративной базы не копируются автоматически. Перед включением необходимы разрешение ИТ-отдела, схема данных, сервисная учётная запись с минимальными правами, VPN/allowlist и тестовый контур.

## Контракт

`integrationConfig()` проверяет выбранный тип; `normalizeTicket(source, item)` и `normalizePerson(source, item)` приводят записи к единому формату. `createCorporateAdapter().health()` показывает готовность конфигурации **без попытки получить закрытые данные**.

Следующий этап: согласовать маппинг полей, права чтения/записи, двустороннюю синхронизацию, аудит и защиту от дубликатов. Не включать синхронизацию в production до аудита безопасности.
