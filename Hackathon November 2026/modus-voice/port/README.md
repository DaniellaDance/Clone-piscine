# Modus Voice — отдельный хостинг

Сборка: npm ci && npm run build. Запуск: npm start.
Секреты: DATABASE_URL и SESSION_SECRET. Не публиковать их в Git.
Состояние хранится в PostgreSQL voice_state; учётные записи в voice_accounts.
Пароли scrypt+случайная соль, HttpOnly Secure SameSite cookies. Клиент видит только свои обращения. Статусы меняют администратор или назначенный сотрудник. Новые логины и подтверждение покупки создаёт администратор вручную; интеграции с продажами нет.
Старый Site остаётся независимой резервной версией. Между старой и новой базой нет автоматической синхронизации.
