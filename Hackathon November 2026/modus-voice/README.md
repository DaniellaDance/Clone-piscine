# Modus Voice / Модус Голос

Работающий хакатонный прототип для ГК «Модус Трейд», Омск. Сайт: https://modus-voice-dani.solidbuttercup.chatgpt.site

## Что работает

- Серверная общая база D1: обращения, обсуждения, поддержка идей, назначения и очередь событий.
- FAQ по 12 темам и эскалация «не разобрался»; двухшаговая форма, приоритет, маршрутизация.
- Статусы: новая — синий, в работе — жёлтый, решена — зелёный; срочная — красный пульсирующий индикатор (отключается при reduced motion).
- Настройка ФИО и рабочих контактов по функциональным группам. Обязательное описание решения.
- Обзор 15 компаний и 3 примеров сбора предложений, с источниками. Подробнее RESEARCH.md.
- Адаптивный интерфейс и устанавливаемая PWA: общий сайт и приложение с одной базой. Это не нативный APK/IPA и не публикация в магазинах.

## Важные границы

Доступ сайта сохранён закрытым. Демо-переключатель сотрудник/клиент/диспетчер показывает сценарии, но **не является разграничением прав**. Все допущенные пользователи видят общую демосреду. До приглашения реальной компании нужны корпоративная авторизация, проверка назначений, серверные права по ролям, журнал администрирования, регламент хранения и согласованные SLA. Не вводите секреты объектов и персональные данные клиентов.

Email, WhatsApp, MAX, Telegram и SMS: создаются записи `outbox` со статусом `not_configured`; **внешние сообщения не отправляются**, провайдеры не подключены. Ввод контактов сам по себе доставку не включает. Нужны утверждённые адресаты, договорённости с провайдерами, секреты на сервере, обработчик очереди с повторами/дедупликацией и подтверждения доставки. Это следующий этап интеграции, не скрытая готовая функция.

Публичная полная оргструктура не подтверждена. Группы поддержки — предложенная функциональная схема. Логотип — из карточки компании Elec.ru, не новый нарисованный знак. Официальное руководство по стилю не получено.

Данные v1 оставались в localStorage браузера; автоматически на сервер не переносились. Архив v1 лежит рядом и не изменён.

## Запуск

Node >=22.13; pnpm 11.25.0. `pnpm install`, `pnpm build`. Для локальной базы: `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_whole_nocturne.sql`. Затем `pnpm dev`.

Исходники Vinext/React, Drizzle schema и SQL включены; конфигурация привязки конкретного закрытого хостинга и секреты не включены. Для отдельного размещения настройте Cloudflare D1 binding DB и приватный шлюз, который сам выставляет `oai-authenticated-user-id`; никогда не доверяйте этому заголовку из публичного интернета. Локальный режим предусмотрен только для localhost/127.0.0.1/terminal.local.

## Проверка

Сборка, типизация, API-сценарий создания → комментарий → изменение статуса → решение, очередь 5 каналов и проверка интерфейса в браузере. Тестовые записи остаются только в локальной базе, в production демоданные не добавляются.
