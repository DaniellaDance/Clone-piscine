# HorseCup — кубок Tomorrow School

Самостоятельная сетевая версия игры на основе публичных исходников «Скачки за кубок Tomorrow School». Авторство оригинальных материалов сохранено: Daniella Flores & AI Alejandro Production. Исходный сайт Freebuff этим проектом не изменяется.

## Запуск

Требуется Node.js 20 или новее. Сторонние зависимости и установка npm-пакетов не нужны.

```sh
cd HorseCup
npm start
```

Откройте http://localhost:3000. Для игры с телефонов в одной Wi-Fi сети используйте локальный IP компьютера и порт 3000. Для игры через интернет разверните сервер с HTTPS. Статический хостинг без Node.js не поддерживает сетевые поля.

## Правила

1. Первый игрок создаёт поле, выбирает сложность и число участников (1–4).
2. Остальные выбирают собственную лошадь и входят по шестизначному номеру поля. Одна лошадь не может принадлежать двум участникам одного поля.
3. Когда все вошли, создатель нажимает «Старт». Голосования за сложность нет.
4. Общий отсчёт — 3 секунды, заезд — ровно 180 секунд. Все отвечают одновременно.
5. Побеждает игрок с наибольшим числом правильных ответов. При равном результате победителей несколько.
6. На финише автоматически появляется окно с пробегом каждой лошади. Правильный ответ приносит 1000 км на лёгком уровне, 2000 км на среднем и 3000 км на сложном. Неверный ответ не добавляет километры. Победитель определяется по правильным ответам, а не по километрам.
7. Исходный банк расширен проверяемыми вариантами задач по Go. Перед стартом сервер раздаёт равные, непересекающиеся наборы выбранного уровня: вопрос не повторяется ни у игрока, ни у его соперников в этом поле. Если набор исчерпан, игрок ждёт общего финиша; заезд не завершается раньше трёх минут.
7. Победителю звучит синтезированное смешное ржание. Звук можно отключить; кнопка на финише воспроизводит его повторно.

Размеры дорожек закреплены для каждого размера экрана; содержание вопроса и число очков их не меняют. Дорожки не создаются заново при каждом обновлении результата. Варианты ответа расположены облачками под вопросом. Выбор лошадей — по изображениям, без цветовых кружков.

## ИИ-соперник

В тренировке на одного игрока можно включить ИИ-лошадь. Это настоящий соперник в зачёте: он отвечает правильно по расписанию и может выиграть. Сохранены интервалы из исходной игры: лёгкий — 12 секунд, средний — 18 секунд, сложный — 36 секунд. Это алгоритмический виртуальный соперник, без обращения к внешней языковой модели. В сетевом заезде с людьми ИИ не добавляется.

## Режимы и комнаты

При запуске выбирается одиночная или командная игра. В одиночной имя необязательно; пустое имя отображается как «Игрок». В командной игре имя обязательно, можно войти по номеру или создать комнату. Создатель задаёт сложность и число участников, копирует номер или делится ссылкой. Ссылка заранее подставляет номер комнаты. Старт даёт создатель после входа всех участников.

## Android

Прямая установка Android без метки Chrome: `/downloads/HorseCup-1.1.apk`. APK — отдельное приложение `kz.tomorrowschool.horsecup` для Android 8.0 и новее, которое открывает игру через системный WebView. Требуется интернет; файлы игры и сетевой сервер обновляются вместе с веб-версией. Необходим только доступ к интернету; доступ к камере, контактам и микрофону не запрашивается. Исходники Android и инструкция сборки находятся в `android/`.

Также HorseCup — устанавливаемое веб-приложение (PWA). На опубликованном HTTPS-сайте нажмите «Установить» либо откройте меню Chrome → «Установить приложение». Оно откроется отдельным окном с иконкой на главном экране. Этот дополнительный браузерный вариант не является APK и на некоторых устройствах получает метку браузера. Сетевая игра требует интернета; при отсутствии связи доступна только сохранённая оболочка.

## Проверки

```sh
npm test
```

Сервер определяет начало, окончание и результаты заезда, проверяет право на старт и повторную отправку ответа. Клиент не получает правильные ответы в данных вопросов. Техническая проверка: `/healthz`.

## Ограничения демоверсии

Поля хранятся в памяти одного серверного процесса. Перезапуск сервера удаляет текущие поля. Для масштабирования на несколько процессов нужны общая база и синхронизация. Фоновая вкладка или потеря сети могут задержать визуальное обновление, но сервер не продлевает трёхминутный таймер. Звук зависит от настроек браузера; после обновления страницы может понадобиться нажатие на кнопку.

До старта создатель выбирает лёгкие, средние, сложные вопросы или все уровни вперемешку. В смешанном режиме километры считаются по сложности каждого вопроса (1000/2000/3000); победитель определяется количеством правильных ответов.

Можно выбрать включительный диапазон квестов от 1 до 12, например 1–5, или один квест (3–3). Фильтр применяется на сервере вместе со сложностью ко всем участникам комнаты; гости видят настройки в лобби.

Обновление: Go-код вопросов отформатирован gofumpt v0.8.0 с многострочными блоками; дорожки показываются только для участников; вопрос следует сразу под ипподромом.
