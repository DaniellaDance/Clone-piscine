IdeaFIX на вашем устройстве

Сайт и приложения используют один аккаунт и общую базу инсайтов.

Android

Откройте мобильную версию в Chrome. В меню ⋮ выберите «Установить приложение» или «Добавить на главный экран» и подтвердите.

Открыть мобильное приложение →

iPhone и iPad

Откройте мобильную версию в Safari → «Поделиться» → «На экран Домой».

Windows / macOS / Linux

Откройте рабочее пространство в Chrome или Edge → меню браузера → «Установить IdeaFIX». Оно запустится отдельным окном.

Открыть приложение для компьютера →

Устанавливаемое веб-приложение (PWA). Отдельных APK и EXE нет. Для входа, отправки и синхронизации инсайтов нужен интернет. Без сети доступна оболочка приложения.
