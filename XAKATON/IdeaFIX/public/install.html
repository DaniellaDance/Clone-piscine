Fix Idea на вашем устройстве

Один аккаунт для сайта и приложения.

Android

Откройте эту страницу в Chrome. Если кнопка установки не появилась, откройте меню ⋮ → «Установить приложение».

Ярлык, созданный через «Добавить на главный экран», может иметь значок Chrome. Для установки приложения выбирайте «Установить приложение», если этот пункт доступен. Вид значка зависит от браузера и телефона.

Старый ярлык можно убрать с главного экрана после установки нового.

Открыть Fix Idea →

iPhone и iPad

Safari → «Поделиться» → «На экран Домой».

Компьютер

Chrome или Edge → меню браузера → «Установить Fix Idea».
