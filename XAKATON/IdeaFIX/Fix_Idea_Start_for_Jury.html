Fix Idea

Система обратной связи и предложений сотрудников: от инсайта до результата.

1. Быстрая проверка готовой программы

Открыть рабочую версию Fix Idea

Откройте ссылку в современном браузере. Для проверки роли директора используйте учётные данные, предоставленные командой отдельно. В открытой регистрации создаётся сотрудник.

Установка приложения PWA — в Chrome / Edge выберите «Установить приложение», на iPhone — Safari → «Поделиться» → «На экран Домой».

2. Исходный код на GitHub

DaniellaDance/Clone-piscine → XAKATON/IdeaFIX, ветка main. Если GitHub показывает 404, организатору нужно предоставить вашему аккаунту доступ к репозиторию.

3. Локальный запуск из исходников

Нужно: Node.js 24 LTS, npm, Git и отдельная база PostgreSQL — локальная или тестовая база Neon. Команды выполняются в терминале.

git clone https://github.com/DaniellaDance/Clone-piscine.git
cd Clone-piscine/XAKATON/IdeaFIX
npm ci
npm run build

Создайте файл .env в папке IdeaFIX со следующим содержимым. Подставьте строку подключения к вашей тестовой базе и придумайте собственный пароль директора:

DATABASE_URL=postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=verify-full
DIRECTOR_PASSWORD=YOUR_LOCAL_DIRECTOR_PASSWORD
PORT=3000
NODE_ENV=development

Для PostgreSQL на своём компьютере используйте подходящую локальную строку подключения; параметр SSL зависит от настройки вашего сервера.

node --env-file=.env server.mjs

Откройте http://localhost:3000. Сервер автоматически применяет schema.sql и upgrade.sql. Пользователь базы должен иметь права создания схемы и таблиц. Не задавайте NEON_FUNCTION=1 при обычном локальном запуске.

Первый вход: логин director, пароль — значение DIRECTOR_PASSWORD из вашего файла. Переменная создаёт директора только в новой базе; она не меняет пароль существующего пользователя. Новые сотрудники регистрируются через форму; роли назначает директор в «Управлении».

4. Что показать жюри за 3 минуты

  1. Инсайт +: создать текстовую идею, выбрать отдел и сохранить. Проверить появление карточки.
  2. Витрина идей: открыть опубликованную идею; показать этапы и историю.
  3. Похожие идеи: под руководителем открыть группу похожих обращений и исходные карточки. Это группировка по тексту и ключевым темам, а не подтверждённое смысловое тождество.
  4. Мир Модус Трейд: нажать метку, открыть сведения об объекте и карточку компании. Между картой и компаниями переключаться без сброса выбранной вкладки.
  5. ИИ Секретарь: показать анализ идеи и окно новостей. Итоги совещаний доступны только директору; журнал интеграции — только администратору.

5. Проверки и внешние сервисы

npm run test:unit

Модульные тесты запускаются без рабочей базы. Интеграционные проверки требуют отдельной тестовой базы; не используйте для них боевую базу.

Ключи Gemini / других ИИ-провайдеров необязательны для базового запуска. Без них помощник использует режим правил; машинный перевод пользовательских текстов требует настроенного провайдера. Голос и видео требуют разрешений браузера. Новости требуют доступа к RSS-источникам; интернет также нужен для входа и работы с облачной базой.

Битрикс24 и Fathom подключаются отдельно директором или администратором. Проверка запуска сама по себе не создаёт внешние задачи и не записывает встречи. Не включайте секреты, файл .env и реальные пароли в GitHub или материалы конкурса.

Если не запускается

  • Ошибка подключения: проверьте DATABASE_URL, доступность PostgreSQL, SSL и права пользователя.
  • Порт занят: измените PORT, например на 3001, и откройте соответствующий адрес.
  • Нет директора: проверьте DIRECTOR_PASSWORD до первого запуска с новой базой.
  • Кнопки не обновились: перезагрузите страницу; для старой установленной PWA закройте и откройте её заново.
